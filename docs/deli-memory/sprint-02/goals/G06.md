## G06.1 — Fail2ban no VPS

**Critério de aceite:** `sudo fail2ban-client status sshd` retorna `Currently banned: 0` (serviço ativo).

### Comandos VPS
```bash
# SSH no VPS (ver memory/vps-infra.md para alias)
sudo apt-get install -y fail2ban

# Configuração mínima
sudo tee /etc/fail2ban/jail.local <<'EOF'
[DEFAULT]
bantime  = 3600
findtime = 600
maxretry = 5

[sshd]
enabled = true
port    = ssh
logpath = /var/log/auth.log
EOF

sudo systemctl enable fail2ban
sudo systemctl start fail2ban
sudo fail2ban-client status sshd
```

## G06.2 — Branches merged stale (TD#54)

**Critério de aceite:** `git branch -r | wc -l` cai em ≥25 após limpeza.

### Identificar e deletar
```bash
# Local: listar branches merged em main
git fetch --prune
git branch -r --merged origin/main \
  | grep -v 'origin/main\|origin/gh-pages' \
  | sed 's/origin\///' \
  > /tmp/merged_stale.txt

cat /tmp/merged_stale.txt   # revisar antes de deletar

# Deletar no remote (cada um)
while IFS= read -r branch; do
  echo "Deletando: $branch"
  git push origin --delete "$branch"
done < /tmp/merged_stale.txt
```

## G06.3 — Triagem branches não-merged (TD#55)

**Critério de aceite:** todas as 29 branches com decisão documentada (merge/discard/keep-ativo).

### Processo
```bash
# Listar não-merged com data do último commit
git for-each-ref --format='%(refname:short) %(committerdate:short) %(authorname)' \
  refs/remotes/origin \
  --sort=-committerdate \
  | grep -v 'main\|gh-pages\|HEAD' > /tmp/unmerged.txt

cat /tmp/unmerged.txt
```

### Categorias
- **Ativo** (≤7 dias): manter, comunicar ao time
- **Stale ≥15 dias sem PR**: discard (push --delete)
- **PR aberto**: aguardar merge ou fechar
