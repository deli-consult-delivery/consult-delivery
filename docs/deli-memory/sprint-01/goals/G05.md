### G05.3 — Migration `aceite_recontratacao` + Bridge

```
/goal
Branch: feat/g05-recontratacao

Migration supabase/migrations/20260525_005_aceite_recontratacao.sql:

CREATE TABLE aceite_recontratacao (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid NOT NULL REFERENCES tenants(id),
  customer_id uuid REFERENCES customers(id),
  whatsapp_jid text,
  pacote_ofertado text NOT NULL CHECK (pacote_ofertado IN ('light','performance','enterprise','growth')),
  status text NOT NULL DEFAULT 'pendente' CHECK (status IN ('pendente','aceito','recusado','sem_resposta')),
  mensagem_enviada_em timestamptz,
  respondido_em timestamptz,
  notas text,
  created_at timestamptz NOT NULL DEFAULT now()
);
ALTER TABLE aceite_recontratacao ENABLE ROW LEVEL SECURITY;
CREATE POLICY "tenant_own" ON aceite_recontratacao FOR ALL
  USING (tenant_id=(SELECT tenant_id FROM profiles WHERE id=auth.uid()));

Endpoint Bridge:
POST /agents/recontratacao/:customer_id/enviar
1. Buscar customer + whatsapp_jid
2. INSERT INTO aceite_recontratacao (status='pendente', mensagem_enviada_em=NOW())
3. Enviar WhatsApp via Evolution API (mensagem do template por pacote)
4. Retornar { success: true, aceite_id }

Smoke:
- SELECT COUNT(*) FROM aceite_recontratacao → 0 (tabela criada)
- POST /enviar para 1 cliente → mensagem_enviada_em preenchida no DB
OUTPUT BRUTO: SELECT id, mensagem_enviada_em FROM aceite_recontratacao LIMIT 1.
```
