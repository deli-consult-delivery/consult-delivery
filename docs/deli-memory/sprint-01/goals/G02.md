### G02.2 — Task `breno-task-extractor`

```
/goal
Branch: feat/g02-breno

Criar trigger/breno/task-extractor.ts:
- schedules.task id="breno-task-extractor" cron="*/30 * * * *"
- retry: { maxAttempts: 3, minTimeoutInMs: 30_000, maxTimeoutInMs: 90_000 }
- run():
  1. Buscar conversas ativas das últimas 30 min (tabela conversations + messages)
  2. Para cada conversa: chamar runtime.executeAgent('breno', { task: 'extract_tasks', messages }, ctx)
  3. Resultado: array de { titulo, descricao, prioridade }
  4. INSERT INTO tarefas_loja (se tabela existir) ou log em agent_runs
  5. logAgentRun com { tarefas_extraidas: N }

Anti-padrão: não processar mensagens que DELI ou agentes enviaram (filtrar sender_jid de bots).

Smoke: rodar task manualmente em Trigger.dev → agent_runs com tarefas_extraidas ≥ 0.
OUTPUT BRUTO: JSON do output no Trigger.dev dashboard.
```

### G02.3 — Task `breno-renewal-monitor`

```
/goal
Branch: feat/g02-breno

Criar trigger/breno/renewal-monitor.ts:
- schedules.task id="breno-renewal-monitor" cron="0 11 * * *" (8h BRT)
- retry: { maxAttempts: 3, minTimeoutInMs: 60_000, maxTimeoutInMs: 180_000 }
- run():
  1. Buscar contratos com vigencia_fim entre hoje e hoje+30d (tabela contratos — try/catch se não existe)
  2. Buscar cobranças atrasadas no Asaas via Bridge GET /asaas/cobrancas-atrasadas
  3. Para cada item: chamar runtime.executeAgent('breno', { task: 'renewal_alert', item }, ctx)
  4. Resultado vai para draft em drafts_deli (channel='telegram_interno') — não para cliente
  5. logAgentRun com { alertas: N }

Anti-padrão: NUNCA enviar mensagem direta ao cliente — draft apenas.

Smoke: verificar tsc --noEmit + export renouvalMonitorTask existe.
OUTPUT BRUTO: resultado do tsc.
```
