```

CREATE TABLE agent_prompts (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_id text NOT NULL,
  tenant_id uuid REFERENCES tenants(id) ON DELETE CASCADE,
  version int NOT NULL DEFAULT 1,
  prompt text NOT NULL,
  active boolean NOT NULL DEFAULT true,
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE(agent_id, COALESCE(tenant_id,'00000000-0000-0000-0000-000000000000'::uuid), version)

ALTER TABLE agent_prompts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "tenant_see_own_or_global" ON agent_prompts
```

### G01.5 — Task `deli-orchestrator-5min`

```
/goal
Branch: feat/g01-deli-core

Criar trigger/deli/orchestrator-5min.ts:
- schedules.task id="deli-orchestrator-5min" cron="*/5 * * * *"

  1. Buscar agent_runs com status='failed' nas últimas 5 min

  5. logAgentRun com { semaforo, motivos }

Anti-padrão: cron de 5min não deve ter retry excessivo (2 tentativas máximo).

Smoke: verificar export e tsc --noEmit sem erros.
OUTPUT BRUTO: resultado do tsc.
```

2. Importar Anthropic SDK diretamente na task — usar `runtime.executeAgent()` sempre
3. `deli-chat-handler` enviar direto ao cliente — apenas draft em `drafts_deli`
4. Migration sem aprovação prévia do SQL — mostrar SQL, aguardar ok antes de `apply_migration`
