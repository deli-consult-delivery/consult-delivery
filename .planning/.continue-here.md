<completed_work>

**Sessão 06/05/2026:**

- **onPaste no campo de mensagem** (`7a8df4e`): Textarea agora captura imagens do clipboard (screenshots, Ctrl+V). Texto cola normalmente via onChange. Imagens são nomeadas `imagem-colada.ext` e enviadas via `sendFile`.
- **ImageLightbox** (`26c834f`): Clique em imagem abre modal fullscreen com zoom via scroll (até 800%), pan com arrastar, botões +/−, % clicável para reset, Esc/clique fora para fechar.
- **Download de mídias** (`ff00d84`): Botão download em imagem (overlay), vídeo, documento e áudio. Usa fetch→blob para funcionar cross-origin (Evolution API / Supabase Storage). Vídeo ganhou player inline nativo.
- **Fix áudio do celular** (`694ccaa`): Filtro `if (!text && !media_url) return` descartava mensagens de áudio que chegam com `media_url=null` no INSERT (preenchido depois no UPDATE). Corrigido para `&& !media_type`.
- **Formatação WhatsApp** (`694ccaa`): `formatWAText()` parseia `*bold*`, `_itálico_`, `~tachado~`, ` ```mono``` `. HTML escapado antes do parse para evitar XSS.
- **Layout compacto** (`95e4485`): Bubble padding 10→7px, font 14→13px, gap mensagens 10→6, área padding 24→14px, input min-height 44→30px, ConvItem avatar 40→34px, filtros depto/tag/status agora em 1 linha com flex:1.
- **Fix nome conversa fromMe** (`e39aefa`): Webhook usava `pushName` (= "Consult Delivery") para nomear conversa ao receber mensagem enviada do celular. Corrigido para buscar `display_name` em `whatsapp_contacts` pelo JID do destinatário.
